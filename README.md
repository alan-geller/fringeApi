# fringeApi: .NET client for the Edinburgh Festivals Listing web API

This library provides a .NET client for interacting with the Edinburgh Festivals Listing web API.
In particular, it allows you to retrieve information about festivals, venues, shows, and performances.
While there is nothing in it specific to the Edinburgh Fringe festival, most of the functionality is 
designed with that festival in mind.

The scenarios that this client library aims to support are described in [scenarios.md](scenarios.md).

The design of the library is described in [design.md](design.md).
